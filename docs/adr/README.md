## ADR Lifecycle

- **Proposed**: Under discussion, not yet decided.
- **Accepted**: Decision made and ready to implement or in effect.
- **Rejected**: Discussed but decided against.
- **Superseded**: Replaced by a subsequent ADR (link the superseding ADR).
- **Deprecated**: No longer applicable or active.

## Creating a New ADR

1. Copy [`template.md`](./template.md) to `XXXX-<title-in-kebab-case>.md`.
2. Fill out the sections succinctly with context, options, decision, and consequences.
3. Add an entry to the table above.
